# Bed Wars helper

A mod for Minecraft Forge 1.8.9 used to extract data from the game to be used in other programs.

## Features
- Reading chat
- Reading players under TAB
- Sending data through a socket

## Usage
The mod sends JSON data to 127.0.0.1 port 52138.
